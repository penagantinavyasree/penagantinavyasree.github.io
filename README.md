# Navya Sree — Portfolio Website

A beginner-friendly, responsive portfolio built with plain HTML and CSS.

## Edit the website
1. Open `index.html` in a text editor (VS Code or GitHub's editor).
2. Search for the placeholder text and replace it with your real information.
3. Update the GitHub profile link and add project/certificate links.
4. Save the file.

## Publish with GitHub Pages
1. Sign in at https://github.com/
2. Create a new **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
3. Upload `index.html` to the root of that repository. You can also upload `README.md`.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait a few minutes, then visit `https://YOUR-GITHUB-USERNAME.github.io`.

Replace `YOUR-GITHUB-USERNAME` with your actual GitHub username.

## Important
The Data Analysis and Machine Learning project cards are placeholders. Replace them with projects you have actually completed. Only list certificates you have earned.
